Propuesta de Producto Educativo Digital

TEMA: El panel de discusión: Diálogos académico argumentados

OBJETIVO GENERAL: Que los estudiantes desarrollen opiniones fundamentadas, escucha activa, pensamiento crítico y voz autoral.

1. Infografía Interactiva

  • Función Pedagógica: Conceptualizar (Definir el "Qué" y el "Por qué").
  • Contribución al Objetivo: Desglosa visualmente un argumento (Afirmación + Evidencia + Razón) y define la escucha activa y la voz autoral.
  • Recursos Humanos: Diseñador y Pedagogo.
  • Recursos Materiales: Canva (o Genially), herramientas de IA, banco de imágenes.
  • Alojamiento y Consulta: Alojada en Google Classroom y/o GitHub Pages. Consultada en navegador web (PC/móvil).
  • Software (Estudiante): Navegador web estándar.
  • Habilidades (Estudiante): Navegación web básica, hacer clic en puntos interactivos.

2. Video Explicativo

  • Función Pedagógica: Modelar (Mostrar el "Cómo" en la práctica).
  • Contribución al Objetivo: Muestra un panel en acción. Los estudiantes observan el lenguaje corporal (escucha activa), la fluidez y cómo se citan fuentes (argumento fundamentado).
  • Recursos Humanos: Pedagogo (guion), Editor de video, Participantes (actores).
  • Recursos Materiales: Cámaras, micrófonos, software de edición (Clipchamp).
  • Alojamiento y Consulta: Alojado en YouTube (privado) e incrustado en Google Classroom.
  • Software (Estudiante): Navegador web.
  • Habilidades (Estudiante): Habilidad básica para reproducir un video.

3. Podcast Educativo

  • Función Pedagógica: Agudizar (Enfocarse en la escucha y el argumento).
  • Contribución al Objetivo: Al eliminar lo visual, fuerza al estudiante a enfocarse 100% en la escucha activa, identificando el tono, las pausas y la estructura del argumento solo por el audio.
  • Recursos Humanos: Pedagogo, Editor de audio, Participantes.
  • Recursos Materiales: Micrófonos de calidad, software de edición (Audacity), IA para limpieza de audio.
  • Alojamiento y Consulta: Archivo .mp3 en Google Classroom o GitHub. Se puede escuchar en cualquier dispositivo.
  • Software (Estudiante): Navegador web o cualquier reproductor de audio.
  • Habilidades (Estudiante): Habilidad básica para reproducir audio.

4. Simulaciones o Juegos Educativos

  • Función Pedagógica: Practicar (Aplicar el conocimiento en un entorno seguro).
  • Contribución al Objetivo: Es la aplicación directa. El estudiante se enfrenta a un escenario (ej. una falacia) y debe elegir la respuesta correcta (basada en argumento, no en opinión), recibiendo retroalimentación inmediata.
  • Recursos Humanos: Diseñador instruccional, Programador (o experto en Genially), IA para escenarios.
  • Recursos Materiales: Software de autoría (Genially, Storyline) o HTML/JS básico.
  • Alojamiento y Consulta: Incrustado en Google Classroom o alojado en GitHub Pages.
  • Software (Estudiante): Navegador web.
  • Habilidades (Estudiante): Lectura de comprensión y habilidad para seleccionar opciones.
